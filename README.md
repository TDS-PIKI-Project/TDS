# TDS (Tower Destiny Survive)
### *HSE students project 2026*

### Описание:
Игрок пытается выжить как можно дольше времени. В этом ему поможет оружие в руках и башня, которую можно улучшать по ходу действия игры.

**Совместимость:** игра доступна в web для любого пользователя <br>
(Windows / iOS / Linux)
<br>
✨✨Присоединяйся прямо сейчас:✨✨
#### https://tds-piki-project.github.io/TDS/

### Структура проекта:

```
TDS/
├── assets                  # Ресурсы для игры
│   └── textures/
├── scenes                  # Игровые сцены
│   ├── enemies/
│   ├── levels/
│   ├── parallax/
│   ├── player/
│   ├── tower/
│   ├── ui/
│   └── weapons/
└── scripts                 # Отдельные скрипты, не привязанные к сценам
│   ├── autoloads/          # Глобальные данные
│   └─ ...
├── index.html              # Экспортированная web-версия
├── index.js
├── index.wasm
├── index.pck
├── main.py                 # Сервер
├── requirements.txt
├── .gitignore
└── README.md
```
### Использованные инструменты

| Инструмент | Назначение |
|:---|:---|
| [Godot 4.4](https://godotengine.org/) | Игровой движок (main core всей игры) |
| git | Хранение исходного кода |
| GitHub Pages | Хостинг игры |
| Supabase | BackEnd сервер с БД на базе PostgreSQL |
| Render Dashboard | Центр управления проектом (БД и логи) |

### Существующий функционал (Игровое ядро)
* Система регистрации/входа в аккаунт
* Сохранение прогресса между сессиями
* Таблица лидеров
* Динамическое построение башни в зависимости от прогресса игрока
* Создание и улучшение этажей башни
* Генерация различных типов врагов
* Автоматическая стрельба (+ мануальное управление)
* UI (паралакс фон) + анимации
* Меню + окончание игры + уровень и тп
